### Описание проекта
Игра в которой вам необходимо оперделить загаданное компьютером число за минимальное количество попток.

### Какой кейс решаем?
Необходимо написать программу, угадывающую число за минимальное количество попыток.

**Условия соренования**
- Компьютер загадыват число, нужно напсать программу, которая угадает его
- Алгоритм учитывает информацию о том больше или меньше полученное число

### Краткая информация о данных
В услових задания даны значения масимального и минимального числа, которое может быть загаданно (100 и 1).  
### Этапы работы над проектом
1. Реализовать алгоритм наиболее эффективно решающий задачу.
2. Оформить код согласно стандарту PEP8.
3. Зафиксировать версии библиотек.
### Результаты
В результате выполненной работы, бфл реализован алгоритм бинарного поиска который, решает задачу в среднем за 4-е попытки.
### Выводы
Алгоритм показал высокую эффективность для решения задачи угадывания числа.
Благодаря поэтапному делению диапазона пополам, программа в среднем угадывает число за 4 попытки, что подтверждает логарифмическую сложность метода (O(log₂N)).
Алгоритм стабилен, прост в реализации и подходит для автоматических систем тестирования или соревновательных заданий.
